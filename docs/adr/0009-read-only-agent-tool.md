# ADR 0009：首个只读工具与会话删除

2026-10-29，离线切片。

`ReadOnlyToolset` 只显式注册 `read_gateway_status`。状态由本地应用传入不可变快照；工具没有目标、身份或命令参数，不读取聊天中的权限声明，不包含凭据或联系人。工具仅在 `MockAdkRunner(status_tool=...)` 显式启用，默认仍无工具。FakeLLM 通过真实 ADK Runner 发起函数调用，工具结果回传到下一轮模型请求；这证明框架调用链和工具目录，并不证明真实模型抵抗提示注入。

会话键集中校验并拒绝空值和 NUL，避免分隔符歧义。`delete_conversation` 是本地 Python API，未暴露给微信或 Agent 工具；与回复在同一 Runner 锁内执行，避免删除后旧轮次再写回。SQLite 测试验证删除后重建 Runner 不再读取该历史，其他会话保留。删除范围是 ADK 会话记录，不声称清除 SQLite 空闲页、备份或测试 FakeLLM 的内存请求记录。没有并发多进程删除保证；当前仅独立离线 Runner。

长期记忆、自动摘要、保留期、真实模型预算插件与主程序集成仍待实现。
