# ADR 0011：ADK 逐调用费用门禁

2026-10-29，先完成离线验证，随后通过[独立合成消息真实工具验证](../model-live-validation-2026-10-29.md)；主程序尚未启用。

`BudgetedAdkModel` 包装 ADK BaseLlm，每次调用前用服务端绑定的账号/会话向持久 UsageLedger 预留费用；工具往返的第二次模型调用也必须重新预留。聊天内容不能选择账单账号。模型 ID 必须匹配已核验价格及委托模型，限制输入、输出、单候选、请求超时和一次请求尝试。Runner 每轮最多4次模型调用。

当前仅支持非流式文本和本地函数工具；拒绝输入媒体、内置工具和缓存配置。价格估算复用标准文本适配器，按照输入UTF-8字节加固定余量估计输入token，输出按上限预留；实际费用使用模型用量元数据结算。输出缺少用量、调用异常或超时均保留预留额，结果不放行；实际超过预留则记录实际费用并报错，阻止将结果当作正常响应。这不是对服务商计费误差或任意自定义模型委托的费用保证。

真实 ADK Runner + FakeLLM 验证：两次普通调用分别结算，预算不足时委托模型零调用，缺失用量保留预留；只读工具一次往返产生两条独立已结算记录。没有API Key或云端请求，测试账单仅为合成数据。

主程序尚未接入此 Runner。真实 Provider 的网络配置、账号模型可用性、SDK重试行为、故障后的保留会话及费用对账仍须有限实测。真实 Hook 群门禁缺口依旧存在。
