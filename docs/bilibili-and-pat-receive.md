# B 站分享与拍一拍接收修复

## 已定位的原因

- 真实 B 站分享卡片为 10,648 字节。已安装的基础 Hook 在
  `CopyValidatedAddMsgString` 中拒绝超过 4,096 字节的内容，导致整个回调缺失。
- 原来的分享解析只保留 `appmsg/title`，没有保留 `appmsg/url` 和 `des`。
- 拍一拍没有经过当前的 SyncBatch 回调。真实通知在
  `Weixin.dll+0x3565370` 进入，调用 `0x23924a0` 解析发起人、聊天、被拍对象。
  同一解析器还被界面重复调用，不能把每一次解析都作为新消息。

## 实现边界

`adapters/hook_event_extension.py` 与 `scripts/run-hook-event-extension.py`
构成可选的 Hook 接收扩展，仍输出现有 Hook callback envelope。业务层使用
`MessageEvent`，不导入 Frida，不改变可替换的 `WeChatGateway` 协议。

扩展只支持 SHA256 为
`f487e4f56930456a25fb0d7b058c77e2dcd364e268d49bdfff4dc0e3be26ba36`
的微信 4.1.10.27。它只复制自然接收中的数据，不主动调用微信函数、不改返回值。

- 长卡片只补充基础 Hook 已丢弃的 4,096–65,535 字节 type 49 消息。
  检查 AddMsg vtable、字段 has-bits、ArenaStringPtr vtable、字符串长度和容量。
- 拍一拍要求解析器调用来自 `0x3563f39`，且同线程正在处理
  `0x3565370` 通知。界面重读路径 `0xa68dff` 不产生回调。
- 校验账号、发起人、目标及群聊 ID，不按昵称猜测身份，不转发自己发起的拍一拍。
- 通过 `127.0.0.1:8080/callback` 进入现有持久队列。
  扩展 outbox 在回调失败时重试同一载荷；可用时用原生服务器消息 ID 去重，
  无服务器 ID 的拍一拍使用本次通知的固定载荷去重，不把界面重读当作通知。
  成功后清除 outbox 正文，完成回执保留七天。
- `127.0.0.1:30003/status` 只展示计数与进程状态，不展示聊天内容。
  管理命令为 `scripts/hook-event-extension.ps1 -Action start|status|stop`。
  停止时让观察器正常卸载，不能强制终止带有重叠观察点的研究进程。

## 网页读取

统一使用 `read_web_page`。B 站视频和解析后为视频的 b23 短链接，使用
`bilibili.py` 的视频专用读取逻辑，返回信息、可用字幕及少量公开评论。
其他链接（包括 B 站非视频页面）使用通用网页阅读组件。
每次跳转都检查域名与 HTTPS，不使用账号 Cookie，不登录，
不绕过访问限制，响应大小和返回文字都有上限。

视频返回 `video_metadata` 或 `video_subtitles`，始终明确
`video_watched=false`。无字幕时只知道标题简介，不能据此描述画面或音频。
视频引用使用去掉分享追踪参数的地址。视频信息与评论分别标记成功或失败；
一部分不可读时保留另一部分，并明确 `partial=true`，不把评论当作视频内容。

真实验收已独立读到用户分享视频的标题、UP 主、23 秒时长及简介；该视频没有
公开字幕。已独立读取公开专栏正文 22,669 字符，无截断。独立读取不触发微信发送。

## 验证与当前部署状态

### 合并到网页阅读的视频评论

网页工具参数为 `read_web_page(url, comment_limit=5, comment_sort="hot")`。
已移除模型可见的独立评论工具。仅 B 站视频自动附带评论，最多十条，可选
`latest` 排序；其他网页忽略评论参数。含可用置顶并去重，不自动翻页或展开楼中楼。每条正文上限
600 UTF-8 字节，评论列表总上限 5,000 字节；返回截断及样本标记。

视频专用读取使用公开信息、字幕及评论接口，不额外调用模型，不下载视频或图片，不使用登录凭据。
直接从视频编号确定公开评论区编号，避免加载播放器及与评论无关的网页信息。
BV 编号格式参考 [abv 的实现](https://github.com/Colerar/abv/blob/main/src/lib.rs)，
并与三个实际页面编号独立核对。接口拒绝访问时返回失败，和成功读取到零条评论区分。
观众评论是样本，不视为视频事实、所有观众的共识或可执行指令。

2026-11-08 实际验收：用户分享视频返回零条；另一个公开视频返回三条评论，
完整工具结果为 1,299 字节。新增七项测试后，完整测试 346 通过、同样三项旧失败。
相关结果为 `.tmp/bilibili-pat-20261107/comments-acceptance.json` 和 `comments-tests.xml`。

统一入口新增五项路由与合并测试，最新完整测试 360 通过，同样三项旧失败。
统一入口真实读取两个视频均取得评论结果；当次视频信息接口受限，已正确返回
部分成功及分项失败标记。结果与测试 XML 位于
`.tmp/bilibili-pat-20261107/unified-reader-acceptance.json`、`unified-reader-tests.xml`。
