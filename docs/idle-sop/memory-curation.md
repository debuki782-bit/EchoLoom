# 记忆写入路由 SOP

1. 先定位原始消息、发送人和精确 ID，再看已有资料；确定这条信息以后是否真的需要跨会话使用。
2. 按“以后要怎么用”选唯一目标：单条消息指代/承诺写消息备注；稳定人物信息写 sender profile；稳定词义写词典；跨聊天待办写事件；账号级稳定事实写长期事实。来源和结论必须分开。
3. 一条内容不要复制到多个类别。若有多种线索，选最重要的一项作为本轮主任务，其他项留待之后，不一次性搬运整段聊天。
4. 更正旧内容时先定位精确 ID，按工具提供的删除/更新方式处理，再写新内容；不要用一个类别的新记录覆盖其他独立条目。
5. 只有工具回执成功才报告已保存。若无需写入，记录理由即可。
