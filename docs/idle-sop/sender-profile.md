# 人物资料核实与新增 SOP

1. 从具体消息出发，核对原文、消息 ID 和准确 sender_id。优先使用已明确的身份/关系、本人表达的稳定偏好、常用称呼或互动习惯；不记录短期状态和推测。
2. 查该发送人的现有资料。资料类型只用于分类，同一类别可有多条独立内容；新增一条时不可把其他偏好合并覆盖。完全重复不再写。
3. Agent 只能维护 sender_updates 中的普通人物资料；人工 Remark 不可由 Agent 写入或删除。昵称、群昵称、Remark 和真实身份不可互相臆造。
4. 新增时只写一条简短、可复用的事实，并保留来源语境。若是在纠正旧资料，先用 sender_deletes 指定精确旧 memory_id，再新增更正内容；确认两个结果都成功。
5. 无法确认是哪个人、资料只出现一次且很临时，或现有内容已经足够时，不新增。总结只报告实际保存的条目及来源消息。
