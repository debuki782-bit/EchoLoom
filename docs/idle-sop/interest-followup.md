# 兴趣线索延伸 SOP

1. 从主人明确表达过的兴趣或最近主动提出的话题中选一条，先读对应消息与现有偏好/事件，确认不是空闲活动刚处理过的主题。
2. 只做一个能延续兴趣的小目标：整理本人提出的问题、对照项目已有资料找出关键分歧，或把零散线索整理成下一次自然可聊的具体问题。不要重复抄写已知背景。
3. 空闲 Agent 没有合适的外部检索工具时，不假装完成了新知识研究；只依据现有聊天和项目资料，并标出未核实之处。
4. 不因发现兴趣就擅自向群友发消息。只有目标会话、关系、上下文和时机都自然，且能提供具体价值时才考虑联系；否则留待主人下次主动提起。
5. 没有新角度就结束，不新增重复偏好或长期事实；总结只保留有用的新问题或明确的未核实点。
