# 语气与表达节奏复核 SOP

1. 只抽查一段最近对话中的 3–8 条 Agent 回复，最好选明确收到过语气反馈的场景；对照当前人设和对方关系，不把风格变成固定模板。
2. 观察是否有具体重复：句尾/颜文字/Emoji 连用、每条都分段、过度解释、过度热络、陌生人面前过早亲昵、面对主要绑定对象又显得疏离，或为了“高冷”而不礼貌。
3. 结合对方的回复和话题变化判断效果。不要仅凭单条短回复推断关系，也不要把默认偏好口吻误当成对方的反应。
4. 找到可复现的问题后，先查事件簿和主提示词是否已有规则。若规则充分，不重复新增；若规则缺失，提出一条短、可执行、适用于明确场景的调整，并给复核或退出条件。
5. 一轮只处理一个表达习惯。没有稳定证据就记“本次未发现可持续调整”，不硬造缺点；总结用一两句说明观察到的例子和结论，不写自我表扬。
