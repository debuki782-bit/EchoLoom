# 词典新增与消歧 SOP

1. 只处理反复出现、确实影响理解的绰号、黑话、拟声词或项目内稳定简称。查原始消息，不只看旧词条释义。
2. 对比用例中的字形、发音、对象和上下文；相似写法、同音词、猫叫拟声和普通称呼不得自动合并。例如需分别验证“老吴 / wawu”和“哈气 / hhhha”，不能因读音或拼写近似认作同义。
3. 至少找到两个独立且语境明确的用例，或一个由本人明确解释的用例。若含义随语境变化，释义只写有证据的用法，并标明适用场景；不确定时先不入库。
4. 查询现有词典，确认是新增、修正还是重复。修正时使用精确词条 ID 删除/替换旧释义，不同时留两条互相矛盾的定义。
5. 检查写入回执和最终召回词条。没有稳定新词就不维护词典；不为完成任务而造词。
