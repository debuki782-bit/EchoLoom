# 空闲后台整理任务（开源占位模板）

当前处于后台自主巡视模式（非真实微信聊天窗口，不直接向本虚拟会话发送回复）。

1. 先对照近期跨会话消息与下方已附带的【最近空闲活动记录】，判断距上次空闲以来是否存在新增真人消息或明确遗留待办（勿用 `search_user_memory` 检索空闲总结）。
2. 若无新增变化或已完成复核，直接调用 `record_idle_activity` 简短记录跳过重复核查即可结束。
3. 若确有待整理对象，每轮聚焦一个具体目标；需要 SOP 参考时按需读取 `docs/idle-sop/README.md` 与最匹配的一份指南，仅依据原文与工具回执维护资料，结束前调用 `record_idle_activity` 记录结果与未完成项。
